Mode opératoire — Comment corriger un observateur ?
  1. Vérifiez le contexte : comparez le nom lu par l'OCR (transcription automatique de la fiche papier) avec l'observateur actuellement enregistré dans la fiche.
  2. Consultez les suggestions : si des observateurs existants ressemblent à plus de 80 % au nom OCR, ils sont proposés automatiquement. Cliquez sur "Sélectionner" pour en choisir un directement.
  3. Ou recherchez manuellement : tapez le nom correct dans le champ de saisie. La recherche se lance automatiquement dès 2 caractères — inutile d'appuyer sur Entrée.
  4. Sélectionnez dans les résultats : cliquez sur pour choisir l'observateur correspondant dans le tableau.
  5. Ou créez un nouvel observateur : si aucun résultat ne correspond, un bouton "Créer" apparaît. Vérifiez bien l'orthographe avant de valider pour éviter les doublons.
  6. Choisissez la portée : dans la fenêtre de confirmation, indiquez si la correction s'applique uniquement à cette fiche, ou à toutes les fiches de cet observateur (fusion avec suppression de l'entrée en double).
