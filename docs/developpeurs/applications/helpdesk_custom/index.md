# Helpdesk Custom - Vue d'ensemble

> Personnalisation du système de tickets django-helpdesk

## Responsabilité

L'application **helpdesk_custom** personnalise django-helpdesk pour :
- Support utilisateurs
- Gestion des tickets d'assistance
- Intégration avec le projet
